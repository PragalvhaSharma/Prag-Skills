# cover-letter

A [Claude Code](https://claude.com/claude-code) skill that writes a cover letter and renders it as a print-ready PDF: one page, Times New Roman 12pt, no em dashes.

Most letters generated by an LLM fail in the same three ways. They run to two pages, they render in whatever sans-serif the browser picked, and they are studded with em dashes. This skill treats all three as build errors rather than style preferences.

## Install

Drop the folder into your skills directory:

```bash
git clone https://github.com/PragalvhaSharma/cover-letter-skill.git ~/.claude/skills/cover-letter
```

Then invoke it with `/cover-letter`, or just ask for a cover letter and it will trigger on its own.

## Use

```
/cover-letter https://careers.example.com/o/some-role
```

The skill reads the posting, pulls your details, drafts to a word budget that actually fits one page, renders, and verifies.

## The verifier

`scripts/build.sh` is the part worth stealing. It renders the HTML with headless Chrome and then refuses to pass a PDF that breaks the rules:

```
$ scripts/build.sh letter.html letter.pdf
ok    1 page
ok    Times New Roman embedded
ok    no em dashes

letter.pdf
```

On failure it exits non-zero, prints exactly what spilled onto page 2, and names the lines containing em dashes. A letter that does not pass does not get sent.

## Layout

```
SKILL.md              instructions, the word budget, the fit-it-to-one-page order
assets/template.html  header, rule, date, recipient, body, sign-off
scripts/build.sh      render and verify
references/style.md   punctuation rules, phrases to cut, what replaces them
```

## Requirements

- A Chrome-family browser for rendering. The script also looks for Chromium and Edge.
- `pdfinfo`, `pdffonts`, and `pdftotext` from poppler for the checks. Install with `brew install poppler`. Without them the PDF still renders, it just goes out unverified.
